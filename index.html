📊 forgestats - Track your software release statistics easily

Download forgestats

forgestats provides a clear dashboard for your project releases. It helps you see download counts from GitHub, GitLab, and Codeberg. The tool also pulls data from SourceForge mirrors. You get a static view of your progress without running a backend server.

📋 What is forgestats?

Managing software releases requires accurate data. You need to know how many people download your work. forgestats collects这 information into a single place. The dashboard displays meaningful charts. It works for open source projects hosted on various platforms.

💡 Frequently Asked Questions

Does this app store my data? No. forgestats is a static tool. It reads data from public sources and shows it to you. It does not send your personal information anywhere.

Can I use this for private projects? This tool focuses on public release stats. Public repositories work best with these data sources.

What platforms does it cover? It tracks GitHub, GitLab, Codeberg, and SourceForge.

🛠️ Troubleshooting

If the dashboard fails to load, check your internet connection. Some firewall settings block external data requests. Ensure your browser stays up to date for the best performance. Refresh the page to reload the latest numbers from the mirrors.
